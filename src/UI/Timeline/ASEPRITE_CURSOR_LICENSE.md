# Aseprite copy cursor — third-party asset

The `cursor_normal_add` image (16×16 pixels) is reproduced **unchanged** from
the official Aseprite Default Theme sprite sheet. The source sheet is embedded
as lossless Base64 PNG in `AsepriteCopyCursor.gd`; at runtime, Pixelorama
extracts the region **x=80, y=16, width=16, height=16**, hotspot **(0, 0)**.
The PNG itself is not redrawn or otherwise modified.
